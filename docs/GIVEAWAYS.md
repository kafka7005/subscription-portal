# Розыгрыши

Для интеграции нужен установленный и включённый модуль бота `giveaways` с настройкой `profile_button`, партнёрскими шансами и очередью выдачи. Этот портал подключается к установленному модулю через его сервисы. На установках без модуля пункт меню скрыт.

Обновите сайт в обычном порядке. На машине бота перенесите `giveaways.py`, `api.py` и `VERSION` из `bot-module/portal_custom_api/` текущего выпуска в одноимённый установленный модуль. Перезапустите службу бота. Для первой установки кастомного API используйте модуль целиком.

Переключатель **Розыгрыши → Показывать розыгрыши в профиле бота и меню кабинета** доступен суперадминистратору с привязанным Telegram. Он меняет настройку бота. Кабинет перечитывает её при возвращении во вкладку и раз в минуту. Ссылки вида `/cabinet/giveaways/ID` работают, пока включён сам модуль. Скрытый завершённый розыгрыш остаётся доступен его участнику по ссылке.

Заявку, проверку условий, выбор победителей и выдачу обрабатывает бот. Сайт использует Telegram ID текущего аккаунта. Персональную кнопку получения приза видит его владелец. Чтобы проверить интеграцию без рассылки, откройте настройки, создайте черновик и проверьте предпросмотр до публикации.
